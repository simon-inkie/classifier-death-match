CLASSIFIER DEATH MATCH

AI models steer fighters round an arena. Every turn each one gets a description of the scene and picks one of eight moves. Typed-decision classifiers return a probability for every option; a chat model, if you add one, is asked for JSON.

Speed matters: a model that answers faster gets more turns. Mock is free and needs no network, Live calls the real models, and Replay plays back saved matches exactly.

The code is open source. No tracking, no sign-up.
